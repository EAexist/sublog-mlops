## About The Project

This is MLOps of Subscription Killer api server.  

For introduction of the app, please refer to following repo of the API server.

<a href="https://github.com/EAexist/subscription-killer-api">Subscription Killer API</a>


This project synthesizes shared dataset for business, and runs benchmark of business tasks with multiple models.

* **Multi-Task Evaluation**

  Each business tasks are benchmarked independently, enabling per-task diagnostics.

* **Automated Dataset Synthesis**

  Dataset, which is used for prompt engineering, eval, and as a sample for business logic, are generated by a oracle LLM and validated before use, ensuring consistent and reproducible benchmarks.

* **Versioned Dataset Publishing**

  Validated datasets are versioned and published to a shared git submodule, making them reusable across business repos and live service with full history and archiving.

* **Config-Driven Model Registry**

  Add a new model with one block in `config/models.yaml` — no code changes required.

* **Infrastructure as Code**

  The process is fully orchestrated by Apache Airflow. Airflow stack is fully reproducible via `make` commands; connections and secrets are seeded from `.env`, never hardcoded.

<!-- GETTING STARTED -->
## Getting Started

```bash
cp .env.example .env   # fill in API keys
make install
make airflow-up
make airflow-seed
# Open http://localhost:8080 (admin / admin), enable benchmark_dag, trigger manually
```

## Commands

| Command | Description |
|---|---|
| `make install` | Install deps (uv sync) |
| `make airflow-up` | Start Airflow stack |
| `make airflow-seed` | Load .env → Airflow Connections |
| `make benchmark-run` | Trigger benchmark DAG |
| `make cli-run` | Run pipeline locally (no Docker) |
| `make submodule-init` | Initialize datasets git submodule |
| `make test` | Run tests |
| `make lint` | Ruff check + format check |
| `make typecheck` | mypy |
