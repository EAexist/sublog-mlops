## About The Project

This is MLOps of Subscription Killer api server.  
For introduction of the app, please refer to following repo of the API server.
<a href="https://github.com/EAexist/subscription-killer-api">Subscription Killer 
API</a>

This project synthesizes datasets for development and testing of the Subscription Killer API project. The datasets are used for AI-backed tasks that are actually used in the Subscription Killer API project when handling requests.

## Core Capabilities

### Automated Dataset Synthesis

Datasets are generated by an oracle LLM and validated before use, ensuring consistent and reproducible benchmarks for the Subscription Killer API development and testing.

### Professional Model Evaluation

Multiple AI models are evaluated on real Subscription Killer API tasks, providing per-task diagnostics to help optimize the API's AI performance.

### Scalability

Designed for Airflow orchestration to enable scalable, production-ready MLOps pipeline execution.

## Getting Started

```bash
cp .env.example .env   # fill in API keys
make install
make cli-run         # Run pipeline locally
```

## Commands

| Command | Description |
|---|---|
| `make install` | Install dependencies (uv sync) |
| `make cli-run` | Run pipeline locally |
| `make test` | Run unit tests |
| `make test-int` | Run integration tests |
| `make lint` | Run ruff check and format check |
| `make lint-fix` | Auto-fix linting issues |
| `make typecheck` | Run mypy type checking |
| `make submodule-init` | Initialize datasets git submodule |
